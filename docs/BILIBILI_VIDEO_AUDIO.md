# B站视频音轨接入与验收

## 使用

```text
@机器人 b站 BV13x41117TL
@机器人 b站 https://www.bilibili.com/video/BV13x41117TL?p=1
```

空闲时直接播放，已有播放时加入现有队列。分P从 1 开始，视频链接中的分享追踪参数会被移除。
Panel 搜索框可输入 `b站:BV13x41117TL`，搜索或直接点歌；同样复用当前队列。

默认启用并自动获取匿名访客身份，不要求手工配置账号 Cookie。
短链接、直播、番剧、关键词视频搜索及会员专属内容不属于本次 BV 直点功能范围。
原有音频区/关键词兼容入口保留，但未作为本次功能的验收依据。
配置与关闭方法见 [配置说明](CONFIGURATION.md#b站视频音轨)。

## 实现边界

- SPI 获取访客标识，NAV 获取 WBI 信息，再按 BV 和分P解析视频与独立 AAC 音轨；不依赖视频网页可访问。
- 待播项保存稳定的 BV/分P信息，不依赖已过期或重启前的临时音频地址；单曲循环也重新解析。
- Bot 进程内的回环流式代理补齐 Referer 并支持 Range，不缓存整个音频到磁盘；最多保存 32 个临时地址并限制 4 个上游并发。
- 代理仅接受受支持的 B站 CDN，拒绝跳转到其他主机；请求中的账号 Cookie、Authorization 不向 CDN 转发。
- 访问受限或无权限时返回错误，不无限重试或将故障当作未找到。
- 不增加 Python/npm 依赖、Compose 服务、公开端口或数据格式迁移。

## 已有验证

2026-10-23，独立测试脚本已在部署服务器验证：

- 无登录 Cookie 自动获取访客身份、WBI 视频信息与 AAC 音轨，CDN 返回 HTTP 206；
- Chromium 通过本机代理读取音频，检测到解码信号和有效音频轨道；
- 播放进度、暂停、继续、跳转、停止检查均通过。

正式实现另已在本机验证匿名解析和回环代理的 8 KiB 音频读取。
以上没有加入 OOPZ 语音频道，不能替代下面的实际收听验收。

自动化覆盖 BV/链接校验、分P、WBI 已知向量、412 冷却、错误数据、Range/CORS、代理边界与连接释放、三种命令入口、待播延迟取址和单曲循环。

## 部署后实播验收

部署包含此改动的 Bot 镜像后，在频道空闲时执行：

1. 在 QQ 群发送 `@机器人 b站 BV13x41117TL`，人工确认 OOPZ 目标频道有声音。
2. 再发送 `@机器人 b站 BV11x411K7CN`，确认排队且没有中断当前歌曲。
3. 执行暂停、继续并调整音量，确认频道实际声音同步变化。
4. 执行切歌，确认第二首实际出声，Panel 与队列同步。
5. 用一个有多个分P的普通视频验证 `?p=2` 的标题、时长与声音匹配；越界分P应明确报错。
6. 保留另一首待播 B站视频并重启 Bot，再切歌，确认重新解析后仍能播放。
7. 执行停止并检查 QQ 音乐点歌仍正常。

完成后才能将“已验证解析与解码”更新为“已验证 OOPZ 实播”。
升级使用 `oopzctl upgrade --ref <包含改动的提交或分支>`，启用 JM 的部署需附带 `--profile jm`；先运行 `--dry-run`。
回滚使用 `oopzctl rollback --release <升级前记录的ID>`；回滚前移除待播 B站条目，保留原有数据与 Redis 卷。
